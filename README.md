# 鐵管裁切計算（PWA）

計算橫桿、斜桿鐵管的裁切長度，可整理成裁切清單。可安裝到手機桌面，離線也能用。

## 計算方式
- **主架管外徑**：可選 Ø48.4、Ø60.2
- **橫桿**：
  - 工件長度 = 管中心到管中心 − 主架管外徑
  - 裁切長 = 工件長度 − 橫桿頭單邊扣除 × 2
  - 輕型橫桿頭扣 42.5，重型橫桿頭扣 50
- **斜桿**：裁切長 = √((水平中心距 − 鉚釘孔偏移 × 2)² + 垂直距離²) + 管端加長 × 2
  - 鉚釘孔單邊扣除：輕型架 82、標準架 99、重型架 103.6（可自訂）；管端加長預設 25
- **定位桿**：
  - 斜邊 = √(水平中心距² + 垂直中心距²)
  - 工件長度 = 斜邊 − 主架管外徑
  - 裁切長 = 工件長度 − 橫桿頭單邊扣除 × 2（輕型 42.5、重型 50）
- **重量（STK500）**：每米重 kg/m = (外徑 − 厚度) × 厚度 × 0.02466（鋼材密度 7.85）
  - 三種規格同時算出重量（每米重 × 裁切長度）：Ø42.5×2.3（2.280 kg/m）、Ø48.4×2.3（2.615 kg/m）、Ø48.4×2.5（2.830 kg/m）
  - 點選其中一種，加入裁切清單時用該規格計重

| 規格 | 裁切長度 |
|---|---|
| 橫桿 1800（輕型頭） | 1666.6 |
| 橫桿 1800（重型頭） | 1651.6 |
| 斜桿 1829 × 1500 | 2291.0 |
| 斜桿 3000 × 2000 | 3520.3 |
| 定位桿 1800 × 1800（輕型頭） | 2412.2 |
| 定位桿 1800 × 1800（重型頭） | 2397.2 |

## 發佈與安裝
1. 到 GitHub 倉庫 **Settings → Pages**，Source 選 `Deploy from a branch`，分支選 `main`、資料夾 `/ (root)`，存檔。
2. 約一分鐘後開啟 `https://<帳號>.github.io/<倉庫名稱>/`。
3. 手機安裝：
   - **Android（Chrome）**：選單 → 「安裝應用程式」或「加到主畫面」。
   - **iPhone（Safari）**：分享 → 「加入主畫面」。

## 檔案
- `index.html`：app 本體
- `manifest.webmanifest`：PWA 設定
- `sw.js`：離線快取
- `icons/`：圖示
